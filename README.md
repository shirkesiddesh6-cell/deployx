# DeployX

DeployX is a self-built Application Deployment and Monitoring Platform designed to demonstrate a complete DevOps workflow.

## Architecture

Developer → Git/GitHub → Application → Docker → Nginx → Kubernetes → Monitoring

## Technology Stack

- Linux (Ubuntu / WSL2)
- HTML, CSS, JavaScript
- Node.js + Express.js
- PostgreSQL
- Nginx
- Docker + Docker Compose
- Kubernetes + Minikube
- Prometheus
- Grafana
- Git + GitHub
- GitHub Actions

## Project Goals

- Build a full-stack application
- Containerize the application using Docker
- Configure Nginx as a reverse proxy
- Deploy the application using Kubernetes
- Use PostgreSQL with persistent storage
- Monitor the system using Prometheus and Grafana
- Build a CI/CD pipeline using GitHub Actions
