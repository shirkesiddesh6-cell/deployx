## What is DeployX?

DeployX is a full-stack web platform that lets users create, view, update, and delete application deployments — and monitor their status through a Grafana dashboard.

It demonstrates the complete DevOps lifecycle: containerization, orchestration, reverse proxying, database management, CI/CD, and monitoring.
